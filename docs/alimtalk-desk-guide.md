# 시간표 알림톡 보내기

라이브 시간표에서 **안내할 수업일**을 열고 **업무 도구 → 시간표 카드 → 시간표 알림톡**으로 들어갑니다.

1. **학부모 발송** 또는 **학생 본인 발송**을 고릅니다. 명단 색상과 이력 모두 선택한 대상 기준입니다.
2. 학생과 번호가 아직 확인되지 않았다면 학생을 고르고 **학생·받는 번호 확인**을 엽니다. 시간표의 수업과 원장의 학생(이름·학교·학년)이 맞는지 확인한 뒤, 그 수업일에 연락해도 되는 사람을 기록합니다. 이 과정에서는 메시지를 보내지 않습니다.
3. 처음 안내할 때는 **학생 일괄 발송** 또는 **학부모 일괄 발송**, 이미 안내한 수업이 바뀌었을 때는 **변경 대상자 알림톡**을 고릅니다. 받을 번호를 체크하고 본문을 열어 봅니다. 변경 안내는 이전 본문도 볼 수 있습니다.
4. **선택 내역 검토**에서 날짜·학생·관계·번호 끝자리와 본문을 확인한 뒤 확인란을 체크하고 건수가 표시된 발송 버튼을 누릅니다. 여러 건을 처리하는 중에는 창을 열어 둡니다. 중간에 창을 닫아도 이미 요청된 건은 취소되지 않습니다.
5. **전체 발송 이력**에서 요청 시각, 수신자, 보낸 본문과 결과를 봅니다. 접수는 아직 수신 완료가 아닙니다. 결과가 남아 있으면 **미확정 …건 결과 갱신**을 누릅니다. 실패가 확정된 번호는 다음 검토에 재시도로 표시되며, 결과가 불명확한 번호는 자동 재시도하지 않습니다.

| 명단 | 의미 |
| --- | --- |
| 연녹색 · 발송 | 선택한 대상의 확인된 번호들이 현재 안내를 수신했습니다. |
| 연빨간색 · 미발송 | 아직 안내가 필요한 번호가 있거나, 학생·번호 확인이 필요합니다. |
| 노란색 · 변경 발송 | 이전에 수신한 안내와 현재 수업 내용이 다릅니다. 이미 받았던 번호만 재안내 후보가 됩니다. |
| 회색 · 결과 확인 중 / 확인 필요 | 처리 중이거나 상태가 불명확합니다. 이력이나 학생 연결을 먼저 확인합니다. |

어머니는 이전 안내를 받았고 아버지는 아직 받지 않은 경우, 같은 학생이라도 어머니 번호는 **변경 대상자**, 아버지 번호는 **미발송** 검토에서 따로 처리합니다. 학생 본인과 학부모 이력, 관리자 테스트, 이미지 수동 전달 기록은 섞이지 않습니다.

모든 수업이 사라지거나 취소된 경우 등원 시각을 안내할 수 없으므로 별도로 확인합니다. 학생의 실제 수업 칸이 바뀌어 원장 연결을 다시 확인해야 하는 경우에도 검토를 마치기 전까지 발송되지 않습니다.
