# 스냅샷 저장 이력 UI

2026-09-30 로컬 구현 문서. 기존 시간표의 조밀한 운영 화면과 색상·버튼 체계를 이어받은 작은 확장이다. 전역 디자인 시스템 변경은 아니며 [PRODUCT.md](../PRODUCT.md)와 [DESIGN.md](../DESIGN.md)는 그대로 따른다.

## 진입과 정보

- 실시간/백업 시간표 라벨 바로 옆에 조회 버튼을 둔다. 너비 40px, 최소 높이 40px이며 18px 인라인 SVG를 사용한다. 접근성 이름과 툴팁은 `스냅샷 저장 이력 조회`다.
- ACTIVE 관리자에게만 버튼을 표시한다. API도 관리자 권한을 검사한다. 아이콘을 숨기는 것만으로 권한을 보장하지 않는다.
- 기본 브라우저 `<dialog>`를 모달로 열고 선택한 날짜의 최근 성공 저장 메타데이터를 최대 50건 보여준다. 실패 시도나 복원 가능한 과거 시간표 원본을 나열하는 기능은 아니다.
- 열은 `저장 시각`, `시간표 날짜`, `변경 건`, `입력자`다. 저장 시각 아래에 원본을 읽은 `조회 기준` 시각을 별도로 표시하며 두 시각 모두 한국시간이다.
- 변경 건은 직전 저장본과 다른 시간·강의실 칸 수다. 첫 저장은 `최초 저장`, 0건은 `변경 없음`으로 표시한다. 입력자는 저장 실행자이며 스프레드시트의 실제 수정자와 다를 수 있음을 설명한다.

## 시각·반응형 규칙

흰 모달, 짙은 파랑 본문, 옅은 파랑 표 머리글과 버튼을 사용한다. 모달은 최대 760px, 화면 양옆 여백은 총 32px이며 최대 높이는 80vh다. 내부 목록은 최대 48vh에서 스크롤된다. 제목 18px, 본문·표 13px, 조회 기준과 모바일 필드 이름은 11px로 구분한다.

데스크톱에서는 네 열의 표로 빠르게 비교한다. 600px 이하에서는 각 기록을 이름표가 붙은 두 열 행으로 바꾸고, 저장 시각과 입력자는 전체 너비를 쓴다. 긴 입력자는 줄바꿈하며 표 머리글은 시각적으로만 숨긴다. 모바일 제목은 16px, 모달 안쪽 여백은 16px다.

## 상태와 조작

| 상태 | 표시·행동 |
| --- | --- |
| 조회 중 | 기존 행을 비우고 `저장 이력을 불러오는 중입니다.`를 표시하며 다시 조회 버튼을 잠근다. |
| 성공 | 최근 건수와 한국시간 안내, 저장 메타데이터를 표시한다. |
| 빈 이력 | `아직 저장 이력이 없습니다.`를 표시한다. |
| 도입 전 저장본 | 기존 저장 시각을 보여주고 과거 변경 건·입력자는 확인할 수 없다고 안내한다. |
| 오류 | 일반 오류는 다시 조회를 안내하고, 인증·권한 오류는 관리자 로그인 확인을 안내한다. |
| 재시도 | `다시 조회`로 같은 날짜의 이력을 새로 요청한다. 원본 Apps Script 조회나 저장을 실행하지 않는다. |

닫기 버튼에 초기 포커스를 두며 Escape도 같은 닫기 경로를 사용한다. 닫으면 기록을 비우고 원래 포커스 대상이 남아 있을 때 복귀한다. 키보드 포커스는 파란 외곽선으로 표시하며 상태 문구는 `role="status"`와 `aria-live="polite"`로 알린다. 스크롤 영역에도 키보드로 접근할 수 있다.

조회 순번·현재 날짜·로그인 세션·모달 열림 상태가 일치할 때만 응답을 반영한다. 닫기·날짜 전환·로그아웃 이후 늦게 도착한 응답이 이전 이력을 다시 채우면 안 된다. 사용자 표시값은 텍스트로 삽입한다.
