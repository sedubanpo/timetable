# 날짜별 등록·임시 연락처

중지생이 임시 특강에 참여할 때 등록 관리의 연락처를 확인하고, 없는 수신 관계의 번호만 날짜별로 보완할 수 있다. 명단에서 학생을 선택하고 `등록·임시 연락처`를 연다. 이름·학교·학년 및 수신자 관계를 확인해 저장한 뒤 `발송 준비 확인`으로 이동한다. 저장 자체는 발송하지 않는다.

- 등록된 학생·모·부 번호가 우선이다. 형식 오류·충돌은 임시 번호로 덮어쓰지 않는다.
- 원장 미등록 학생은 시간표의 이름·학교·학년으로 해당 날짜에 한정한 안내 대상을 생성한다. 원장 등록·중지 상태는 변경하지 않는다.
- 동명이인은 사용자가 선택한다. 학교·학년 불일치, 삭제·비활성화·다른 관 원장은 우회하지 않는다.
- 임시 번호는 관계별로 입력·유지·수정·삭제한다. 저장은 수업일별이고 재사용 승인 없이 다른 날짜에 적용되지 않는다.
- 수업 시간 메모와 원본 해석 보류는 연락처 저장으로 해제되지 않는다.
- 새 `timetableNoticeContacts`, `timetableNoticeGuests` 컬렉션은 Admin SDK 전용이다. 운영 규칙 수정은 필요하지 않으며 기존 catch-all deny에 포함된다. 감사 기록에는 임시 번호 원문 대신 해시를 남긴다.
- 수업 원본, 학생 신원, 연락처 버전, 동시 편집, 수업 셀 소유권을 재검사한다. 변경된 번호·매핑은 이전 발송 준비를 무효화한다.
