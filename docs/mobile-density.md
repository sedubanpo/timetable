# 모바일 시간표 가독성 개선 — 2026-10-21

## 변경
- 첫수업 자동 안내에 학생명과 과목·강사를 표시한다. 학생·학교 기준으로 중복을 합치고 서로 다른 과목·강사 조합은 모두 표시한다. 추가 데이터 조회 없이 시간표 렌더링 정보를 사용한다.
- 768px 이하의 강사·실무자·관리자 화면에서 날짜, 검색, 출결 전달함을 우선 표시한다. 나머지 기존 도구는 펼침 버튼에서 접근한다. 조회용 계정의 화면은 유지한다.
- 실무자·관리자도 모바일에서 세로 학생 목록과 심플뷰를 이용한다. 학생 행 여백과 반복 설명을 줄이고 과목·강사·강의실을 유지한다. 상세뷰는 수업 없는 시간대 카드를 생략하며 수업이 전혀 없으면 기존 빈 상태를 표시한다.
- 검색과 심플뷰 전환, PC 전환 시 기존 시간표 복원을 유지한다. 인증·서버·원본 데이터·출결 저장 계약 변경 없음.

## 검증
`scripts/mobile-timetable-density-test.mjs`에서 실제 배포 HTML을 로컬 제공하고 외부 요청을 차단한다. 인증과 학생 기록은 demo-first-lesson 합성 mock이다. 강사 심플뷰·상세뷰·관리자를 1440×900, 390×844, 320×568에서 검증했다.

- 9개 시나리오: 자동 안내, 과목·강사 표시와 중복 병합, 첫수업 태그 기록, 도구 펼침/접힘, 모바일 검색, 긴 글 스크롤, 포커스 복귀, 재렌더링 후 재조회, 오류·상한·timeout 처리 통과.
- 기존 단위/계약 28개, 조회 안정성 브라우저 27개, review-checks, performance-enrollment-checks, export-freshness-test 통과.
- 변경 전후 같은 합성 데이터의 390px 강사 심플뷰: 상단 314→197px, 첫 학생 시작점 532→369px. 320px에서는 상단 361→197px, 첫 학생 579→369px. 실제 단말 성능·화면 측정값으로 일반화하지 않는다.
- 변경 전 상세뷰에 수업 없는 시간대가 누적되던 점도 확인했다. 신규 상세뷰는 실제 학생 수업부터 표시한다.
- mock은 운영 보안 규칙과 실제 강사 로그인 권한을 입증하지 않는다. 물리 iPhone/Safari 검증은 미실시다. 외부 이미지 차단 때문에 합성 화면의 로고는 로드되지 않을 수 있다.
