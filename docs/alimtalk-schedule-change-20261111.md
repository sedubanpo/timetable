# 시간표 변경 안내 분류 및 위치 이동 복구

## 확인한 운영 상태

2026-11-12 기준 김현서는 학부모·학생 알림톡 발송 이력이 없었다. 정준우는 양쪽 수신 이력이 있으며, 영어 20:00–22:00 강의실이 본관 4강의실에서 3관 2강의실로 바뀌었다.

기존 수업 ID는 학생 ID가 아닌 날짜·시간·열·행 위치의 해시다. 시간표 이동으로 같은 위치를 다른 학생이 사용하면 이전 위치 소유자를 보고 자동 연결을 막았다. 새 시간표의 전체 검증 계획에서 기존 학생도 그 위치를 떠난 것이 확인되면 모든 연결을 하나의 트랜잭션으로 갱신하도록 수정했다.

## 보호 조건

- 기존에 실무자가 확인한 학생 신원, 현재 이름·학교·학년, 원장 버전이 모두 일치해야 한다.
- 이전 학생의 검증된 대체 계획이 없거나 같은 위치를 계속 사용하는 경우 재배정하지 않는다.
- 기존 연결과 새 수업의 fingerprint가 같으면 소유 충돌로 보류한다.
- 이전 학생의 연결이 보류되면 그 위치를 사용하는 후속 학생도 보류한다.
- 저장 시 기존 위치의 학생·연결 버전·fingerprint를 다시 대조하며, 오래된 시간표로 되돌리지 않는다.
- 발송 시에는 현재 시간표·연락처·수신 이력을 다시 검증한다. 이 개선 자체가 메시지를 자동 발송하지 않는다.

## 화면

변경된 안내는 노란색 ‘시간표 변경 · 안내 필요’ 그룹과 ‘시간표 변경 · 새 안내 필요’ 카드 라벨로 표시한다. 카드 오른쪽 ‘변경 발송’은 현재 선택한 학부모/학생 대상의 해당 학생에게만 최신 시간표를 전송한다. 아직 안내하지 않은 시간표는 ‘발송 대기’로 구분한다.

검증: 연결 이동/소유 충돌/경합/오래된 원본/변경 발송/학생별 부분 갱신 등 관련 테스트 66개 통과. 외부 통신을 차단한 PC·모바일 화면에서 카드 버튼과 변경 라벨을 검증했다.

운영 검증: 배포 후 학부모·학생 메뉴 모두 정준우가 ‘시간표 변경 · 안내 필요 / 변경 발송’, 김현서가 ‘발송 대기 / 발송’으로 표시됨을 확인했다. 저장된 이전 위치와 현재 시간표를 비교한 결과 두 학생의 수업 위치가 서로 바뀌어 연결을 막고 있었으며, 자동 연결 갱신으로 해소됐다. 이번 작업에서는 추가 메시지를 발송하지 않았다.
