# 시간표 대체 문자 본문 수정

솔라피의 자동 문자 변환에 맡겼던 본문에서 `17:00–19:00`의 구분자가 사라져 `17:0019:00`으로 표시되고, 문자에 없는 ‘수업 문의 버튼’을 안내하는 문제가 있었다.

서버가 알림톡에 사용하는 동일한 검증된 변수로 별도 LMS 본문을 구성한다. 시간 구간은 `17:00 ~ 19:00`, 수업 번호는 `1.`, 구분 표시는 `/`로 출력한다. 버튼 안내 대신 `수업 일정 변경 문의:`와 `https://pf.kakao.com/_KIZxin/chat`을 본문에 넣는다.

`messages[].replacements`에 동일 수신번호의 LMS 한 건만 지정한다. 기존 알림톡 템플릿·치환 변수·문의 버튼은 유지하며, 대체 발송을 끈 테스트 경로에는 replacement를 추가하지 않는다. 외부에서 전달한 대체 수신번호·본문은 사용하지 않는다. 이 변경은 새로 접수하는 알림톡이 실패했을 때 적용되며, 기존 기록 재발송이나 별도의 문자 발송을 실행하지 않는다.

근거: [솔라피 메시지 API의 replacements](https://solapi.com/developers/api/messages), [솔라피 대체 발송 최적화 예제](https://solapi.com/blog/tutorial-asp).

검증:

- provider/runtime/service/batch 관련 테스트 57개 통과. 요청 전송은 모두 mock으로 대체했다.
- 실제 조회해 두었던 11/12 기록 96건을 오프라인으로 변환하여 모든 시간 구분자, 문의 링크, 문자 길이를 확인했다. 보수적으로 ASCII 1바이트·그 외 2바이트로 계산한 최대 본문은 411바이트였다.
- 반시간 수업, 여러 수업, 자정 종료, 원래 알림톡 변수 보존, 동일 수신번호 제한, 대체 발송 비활성화, 결과 조회·중복 방지 경로를 확인했다.
- 보안 규칙용 별도 스크립트는 로컬 Firestore 에뮬레이터가 실행되지 않아 연결에 실패했다. 이번 변경은 규칙을 수정하지 않으며 위 57개 관련 테스트는 모두 통과했다.
- 사용자 지시에 따라 실제 발송·재발송은 하지 않았다. 실단말 수신 시험은 수행하지 않았다.
