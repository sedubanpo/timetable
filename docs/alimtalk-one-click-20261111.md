# 개별 카드 바로 발송 및 부분 갱신 — 2026-11-11

- 학생 카드의 발송·재발송·변경 발송 버튼은 추가 체크 없이 해당 학생과 현재 대상(학부모/학생)의 확인된 번호로 발송한다. 일괄 발송의 선택 화면은 유지한다.
- 버튼 클릭 후 서버에서 최신 원본 수업, 학생 연결, 연락처 확인, 기존 발송 기록, 템플릿을 확인한다. 해당 학생에게 발급된 발송 티켓만 사용하고 전송 시 다시 검증한다.
- 준비 중부터 중복 클릭을 막고 진행 상태를 표시한다. 접수 완료와 수신 완료는 구분하며 오류 발생 시 자동 재발송하지 않는다.
- 개별 미리보기와 후속 명단 조회는 studentIds로 범위를 제한한다. 발송 후 해당 학생을 임시 결과 확인 상태로 반영하고, 목록과 스크롤을 유지한 채 해당 학생만 서버에서 갱신한다. 후속 조회 완료를 기다리지 않고 다음 학생 작업이 가능하다.
- 날짜·대상·로그인이 바뀐 뒤 도착한 응답은 현재 화면에 섞지 않는다. 조회 지연은 해당 카드에 표시한다.
- 접수 ID 누락 건은 일반 결과 대기와 구분해 ‘접수 확인 필요’에 표시한다. 김강훈의 최초 접수 미확정 상태를 임의로 실패나 성공으로 바꾸지 않는다.
- 카드 버튼 최소 클릭 영역 40px. 진행 상태와 목록 조회는 별개로 표시한다.

## 검증

- 서비스·공급자·일괄 발송·UI·HTTP·런타임·전송 어댑터 테스트 101개 통과.
- 합성 데이터와 네트워크 차단 환경에서 PC 1440×1000 / 모바일 390×844 한 번 클릭 발송 흐름, 체크박스 제거, 다음 학생 작업, 접수 미확정 분리 검증.
- 운영 메시지 발송 없이 배포 후 읽기 화면 확인.
